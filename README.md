# 🏡 AI-каталог недвижимости и обмена валют на Кипре (Пафос)

Современная система на языке Python (`aiogram 3` + `telethon` + `Google Gemini AI` / `OpenAI GPT-4o-mini`), которая отслеживает публикации в Telegram-каналах в реальном времени, классифицирует их нейросетью по строгим критериям и отправляет подписчикам в удобном человеческом формате.

---

## 🔥 Что умеет система
- **Интеллектуальный анализ через ИИ (Gemini / OpenAI)**: ИИ сам внимательно читает текст объявления, отсеивает ищущих аренду, не путает виллы за миллионы евро с арендой, извлекает точные цены и валюту.
- **Единый сервер в одном окне**: и сам Telegram-бот (меню, кнопки, фильтры), и юзербот (чтение закрытых и открытых чатов без прав админа) работают параллельно в одном процессе `asyncio`.
- **Живой формат сообщений**: карточки объявлений выглядят как аккуратный дайджест агентства недвижимости без роботизированных фраз.

---

## 🛠 Установка и настройка

1. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```
2. **Создайте или проверьте файл `.env`**:
   ```ini
   BOT_TOKEN=ваш_токен_бота
   CHANNELS=cyexchange, nedvizhka_Ciprus
   
   # Данные Telegram для чтения любых чатов без прав админа (получить на https://my.telegram.org/apps)
   API_ID=35554083
   API_HASH=f3308dd71c039f71e565eabe1938e8f8

   # Ключ нейросети (можно указать Gemini и/или OpenAI)
   GEMINI_API_KEY=ваш_ключ_gemini
   OPENAI_API_KEY=ваш_ключ_openai
   ```

---

## 🚀 Запуск (Всё в одном окне!)

Теперь не нужно открывать два разных окна! Просто запустите:

```bash
python main.py
```
*(Или `python bot.py` — результат тот же).*

### Что произойдёт при запуске:
1. Юзербот подключится к Telegram и проверит последние сообщения из каналов с помощью ИИ.
2. Бот параллельно начнёт принимать команды от пользователей (`/start`, кнопки меню, изменение бюджета).
3. В консоли будет отображаться статус обоих сервисов.
